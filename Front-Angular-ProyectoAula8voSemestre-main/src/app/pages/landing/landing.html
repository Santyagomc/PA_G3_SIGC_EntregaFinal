Qué es SIGC PQRS

Es el canal digital para que ciudadanos y entidades interactúen con la Gobernación del Huila de forma ordenada. Puede conocer el tipo de trámite que le corresponde, qué documentos suelen pedirse y los tiempos orientativos de respuesta antes de registrarse.

Transparencia

Seguimiento claro de solicitudes para usuarios autenticados.

Orientación

Asistente 24/7 para dudas sobre PQRS y documentación.

Radicación

Registro e ingreso de solicitudes formales con cuenta.

Tipos de trámite

  • Petición — Solicitud de información, copias o certificaciones.
  • Queja — Manifestación de inconformidad con el servicio o la atención.
  • Reclamo — Exigencia de solución ante un daño o incumplimiento.

No está seguro cuál aplica? Use el asistente: descríbale su caso o adjunte un documento y le orientamos con preguntas guía.

Documentos y archivos

De forma general se solicitan identificación, formularios o evidencias según el caso (PDF, imágenes, etc.). En el asistente puede subir un archivo para decir «quiero saber si esto sirve como soporte» o escribir libremente qué documento tiene o necesita.

La vinculación oficial de archivos a una solicitud radicada se hace tras iniciar sesión en el módulo de documentos.
